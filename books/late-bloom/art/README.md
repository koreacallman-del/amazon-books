# 작화 엔진 — 「시계가 멈춘 마을」

133쪽 그림책 본문을 코드로 생성한다. 그림을 한 장씩 손으로 그리면 선 굵기와
여백이 미세하게 흔들리므로, 엔진을 짜서 생성한다. 133장이 한 코드 경로를
지나므로 스타일이 흔들릴 구조가 없고, 선 굵기 하나를 바꾸면 전체가 따라온다.

## 다시 만들기

```
python3 -m pip install reportlab pymupdf python-docx   # ← python3 -m pip 로 할 것
python3 build.py        # SVG 133장 + 인쇄용 PDF + proof.html
python3 make_docx.py    # 워드 편집본
```

**주의:** 이 컨테이너는 `pip`이 python3.13을, `python3`이 3.11을 가리킨다.
그냥 `pip install` 하면 다른 인터프리터에 깔려 `ModuleNotFoundError`가 난다.
반드시 `python3 -m pip`를 쓸 것.

## 산출물

| 경로 | 용도 |
|---|---|
| `out/svg/p001.svg` … `p133.svg` | **낱장 그림.** 페이지 번호 = 파일명 숫자 (3자리 0채움, 1부터 133) |
| `out/late-bloom-interior.pdf` | **KDP 인쇄 제출용.** 8.5×8.5in, 134쪽(133 + 판권면), 벡터 |
| `out/시계가-멈춘-마을.docx` | 검토·편집용. 그림은 배경(behindDoc), 글은 편집 가능 |
| `out/proof.html` | 전장 열람용 |

### SVG 사양
- `viewBox="0 0 100 100"` 정사각. 판형 8.5×8.5in에 비례 매핑
- 종이 바탕(`#F6F1E6`)이 `<rect>`로 깔려 있다. 투명 배경이 필요하면 그 rect를 지운다
- 벡터이므로 어떤 해상도로든 확대된다 (쇼츠·인쇄 공용)
- 글자는 **그림에 굽지 않았다.** `<text>`로 따로 들어가 있어 지우거나 다른 언어로 바꿀 수 있다
- 색은 먹(`#1C1A17`)·옅은 먹(`#56504A`)·금(`#A8822F`) 셋뿐

## 구조

| 파일 | 역할 |
|---|---|
| `ink.py` | 선의 질 — 먹선·금선·실금·빗금·엮임·실루엣. SVG·PDF 이중 렌더러 |

| `make_docx.py` | 워드 편집본 |

## 고정된 규칙 (저자 결정)

1. 스타일 고정 — 133장이 한 코드 경로
2. 새·고양이는 눈 없는 붓 실루엣
3. p.104는 60대의 손 유지 (아이 손 쓰지 않음)
4. p.101은 아이콘 5개 예외 허용
5. 금빛은 30쪽만 (`GOLD_PAGES`)

## 떨림(tremble)

선에 미세한 흔들림을 준다. 기계적인 직선은 인쇄물에서 차갑게 보이기 때문이다.
시드를 페이지 번호로 고정했으므로 **몇 번 생성해도 같은 그림이 나온다.**

## 인쇄 규격

- 재단 8.5×8.5in · 블리드 필요 시 위·아래·바깥 각 0.125in
- 책등 쪽 안전 여백 0.375in — 홀수 쪽은 왼쪽, 짝수 쪽은 오른쪽
- `build.py`가 모든 획의 x좌표를 파싱해 침범을 검사한다. 판면 밖으로
  의도적으로 나가는 획(다음 장으로 이어지는 주선, 화면 밖 담벼락)은
  `Stroke.bleed = True`로 표시해 검사에서 제외한다
