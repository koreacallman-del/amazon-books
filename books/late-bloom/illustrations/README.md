# 삽화 폴더

저자가 생성한 그림이 들어가는 자리다. **원본을 여기에 올린다.**

## 현재 상태

| | |
|---|---|
| 필요한 수 | **122장** (본문 133쪽 − 장 제목 9쪽 − 표제지·판권면) |
| 원본 도착 | **0장** |
| 임시 보관 | 10장 (`_chat-preview/` — 아래 참조) |

## `_chat-preview/`는 원본이 아니다

채팅으로 전달된 사본이다. 1536×1024 webp, 장당 약 100KB.
저자 노트북의 `illustrations.zip`은 198MB / 122장 = 장당 약 1.6MB이므로
**원본은 이보다 크고, 이 사본은 인쇄에 쓸 수 없다.**

원본이 올라오면 이 폴더는 지운다. 그때까지 참고용으로만 둔다.
(채팅 전달이 불안정해서 30장 중 10장만 파일로 도착했다. 이 경로는 쓰지 않는다.)

## 올리는 방법

압축을 풀고, 낱장 원본을 이 폴더에 올린다. 장당 1.6MB면 GitHub 제한
(파일당 25MB)에 한참 못 미친다. 한 번에 100개까지이므로 두 번에 나눈다.

```
https://github.com/koreacallman-del/amazon-books/upload/claude/setup-nxarkt/books/late-bloom/illustrations
```

## 올라온 뒤 확인할 것

`art/build.py`가 자동 검사한다.

- **해상도** — 8.5인치 폭을 300dpi로 채우려면 2550px. 미달이면 KDP가 저해상도 경고를 띄운다
- **비율** — 책은 8.5×8.5 정사각. 3:2 가로 그림은 양옆이 잘리거나 띠로 앉혀야 한다
- **장수와 순서** — 파일명 순서로 쪽에 대응시킨다. 빠진 번호를 찾는다

## 화풍이 바뀐 점

`art-direction-v2.md`의 원래 방향은 "사물 하나 + 여백 70%, 배경·인물 없음,
먹 단색 + 금빛 1색"이었다. 저자가 생성한 그림은 인물·배경·원근이 있는
수채 삽화다. 방향 변경은 저자 결정이다.

다만 원래 1순위 조건이 "스타일 고정"이었음을 기록해 둔다. 122장을 같은
인물·같은 옷·같은 색감으로 유지하는 것이 이 방식의 최대 위험이다.
`art/` 의 벡터 작화본(133장)은 비교·대체용으로 보존한다.
