# 일러스트 작업 규격서 — 「시계가 멈춘 마을」 그림책판

작성: 편집장 · 2026-09-27
대상: 일러스트레이터 (또는 AI 이미지 생성 작업자)
정본: `manuscript-v8.docx` / 페이지 배치는 `v8-page-map.md`
출간 형태: 아마존 KDP 페이퍼백 (영문판). 한국어판은 국내 플랫폼 별도.

---

## ⚠️ 먼저 읽을 것 — 그림 스타일이 책 가격을 결정합니다

이게 이 문서에서 가장 중요한 부분입니다. **어떤 잉크로 인쇄되는지가 그림 스타일에 따라 갈리고, 그게 정가의 최저선을 정합니다.**

134페이지 기준 인쇄비와 수익 (미국, 정가 $14.99 가정):

| 잉크 종류 | 어떤 그림인가 | 권당 인쇄비 | $14.99 판매 시 인세 | 손익분기 정가 |
|---|---|---|---|---|
| **흑백** | 먹선, 펜화, 단색 | 약 **$2.28** | **$6.71** | 약 $3.80 |
| **표준 컬러** | 제한된 색, 단색+포인트 1색, 여백 많음 | 약 **$4.42** | **$4.57** | 약 $7.37 |
| **프리미엄 컬러** | 수채화 풀컬러, 전면 채색 | 약 **$9.71** | **–$0.72 (적자)** | 약 **$16.18** |

**프리미엄 컬러로 가면 $14.99에 팔아도 적자입니다.** 정가를 $17.99~19.99로 올려야 겨우 남습니다. 무명 저자의 데뷔작을 $19에 파는 것은 매우 어렵습니다.

### 그래서 내리는 art direction

> **⚠️ 2026-09-30 갱신:** 아트 디렉션이 "손과 선"에서 **"사물 중심"**으로 변경되었다 (저자 승인).
> 페이지마다 그 페이지의 사물을 그리되, 사물 하나 + 여백 70%. 손은 32%의 페이지에만.
> **확정 시안: `art-direction-v2.md`** (구안 `art-direction.md`는 비교용으로 보존)
> 아래 인쇄비·색 제약은 변경 없이 그대로 유효하다 — 단색(먹) + 금빛 1색은 v2에서도 동일하다.

**색 제약은 그대로입니다. 단색 + 포인트 1색을 넘지 마십시오.**

- 배경 없음, 여백 많음, 손 하나 + 선 하나
- 색은 **단색 + 포인트 1색**(금빛)까지. 전면 채색 금지
- 수채화 풀컬러 전면 스프레드로 가면 → 프리미엄 컬러 → 정가 $19 → 안 팔림

원래 기획하신 "손과 선"(먹선·금박·실·콜라주)은 **표준 컬러 또는 흑백+금색 1도로 인쇄 가능한 스타일**입니다. 우연이 아니라 이 콘셉트가 원래 그런 책입니다. 바꾸지 마십시오.

### 페이지 수도 비용입니다
133페이지는 많습니다. 페이지당 비용이 붙기 때문에, **96~100페이지로 줄이면** 인쇄비가 눈에 띄게 내려갑니다 (표준 컬러 100p = 약 $3.55). 원래 "손과 선" 기획이 94페이지였던 것은 좋은 판단이었습니다.

## 1. 판형 및 페이지 규격

| 항목 | 값 |
|---|---|
| 재단 크기(trim) | **8.5 × 8.5 인치** 정사각 |
| 총 페이지 | 현재 133 → **134로 맞춰야 함** (인쇄는 짝수 페이지 필수) |
| 해상도 | **300 DPI 이상** |
| 색 공간 | CMYK 권장 (RGB 제출 시 색이 변할 수 있음) |

8.5×8.5는 KDP 정식 판형이며, 그림책의 표준 사이즈입니다. 선택이 맞습니다.

### 그림이 페이지 끝까지 닿는 경우 (full bleed)
**작업 캔버스 크기를 키워야 합니다.**

| 항목 | 값 |
|---|---|
| 작업 페이지 크기 (블리드 포함) | **8.625 × 8.75 인치** |
| — 가로 | 8.5 + 0.125 (바깥쪽만) |
| — 세로 | 8.5 + 0.125 + 0.125 (위·아래) |
| 300DPI 픽셀 | **2,588 × 2,625 px** |

블리드는 **바깥쪽·위·아래에만** 붙입니다. 책등(안쪽) 쪽에는 붙이지 않습니다.

### 안전 영역 (중요한 것을 넣지 말아야 할 여백)

| 여백 | 최소값 |
|---|---|
| 안쪽(책등 쪽, gutter) | **0.375 인치** — 134페이지 구간 기준 |
| 바깥·위·아래 | 0.25 인치 (블리드 있는 페이지는 **0.375 인치**) |

**텍스트와 손·선의 핵심 부분은 재단선에서 0.25인치 안쪽에** 두십시오. 책등 쪽은 0.375인치 이상 비워야 제본에 물려 안 보이는 사고가 안 납니다.

정사각 판형에서 안쪽 0.375인치는 생각보다 크게 먹힙니다. **손이 책등 쪽으로 뻗는 구도는 피하십시오.**

## 2. 표지 규격

| 항목 | 값 |
|---|---|
| 책등 폭 | **0.302 인치** (백색지 134p 기준) / 크림지는 0.335 인치 |
| 전체 표지 PDF 가로 | **17.552 인치** (뒤표지 8.5 + 책등 0.302 + 앞표지 8.5 + 블리드 0.25) |
| 전체 표지 PDF 세로 | **8.75 인치** (8.5 + 블리드 0.25) |
| 300DPI 픽셀 | **5,266 × 2,625 px** |
| 파일 형식 | **단일 PDF 1장** (뒤표지 + 책등 + 앞표지가 이어진 한 장) |
| 책등에 제목 인쇄 | ✅ **가능** (79페이지 이상이므로) |

책등 텍스트는 폭이 0.302인치뿐이므로 얇습니다. 제목만 넣고 부제는 넣지 마십시오. 재단 오차를 감안해 책등 텍스트는 양옆 0.0625인치를 비웁니다.

### 표지 아트디렉션
표지는 판매의 절반입니다. 독자는 몇 초 안에 결정합니다.

- 중심 이미지: **멈춘 시계탑 하나** (원고의 중심 이미지와 일치)
- 또는 손과 선 콘셉트를 표지에도: **손 하나가 멈춘 바늘을 만지려는 순간**
- 장르 관습: 부드러운 채도, 사진이 아닌 일러스트, 인물은 작거나 뒤돌아 있음
- 참고할 장르: 한국형 힐링 소설 영문판 표지들 (Hyunam-dong Bookshop, Marigold Mind Laundry, DallerGut Dream Department Store)
- **아동 그림책처럼 보이면 안 됩니다.** 8.5×8.5 정사각은 아동서 판형이라 이 위험이 실재합니다. 채도를 낮추고, 캐릭터를 귀엽게 그리지 말고, 폰트를 성인용으로.

## 3. 작업 순서 제안

1. **`v8-page-map.md`를 먼저 읽으십시오.** 133페이지 각각에 어떤 텍스트가 놓이는지 정리돼 있습니다. **각 페이지의 텍스트가 그 페이지의 한 장면입니다.**
2. 전환점 페이지를 먼저 그리십시오 (아래 목록). 이 페이지들이 책의 골격입니다.
3. 나머지를 채우십시오.
4. 표지는 본문 스타일이 확정된 뒤에 마지막에.

### 우선 작업할 전환점 (원본 기획의 ★ 지점 + v8 반영)
| 장면 | 손 | 선 |
|---|---|---|
| 전화기가 울리지 않음 (도입) | 빈 손이 전화기를 쥔다 | 균열, 차갑고 날카로움 |
| 수리공이 도구를 내려놓는 순간 | 도구를 놓는다 ★ | 직선(바늘) 옆의 곡선(바람) |
| 물뿌리개를 기울임 | 기울인다 ★ | 경계를 넘는 물줄기 |
| "늦게 핀 꽃은 오래 간다" | 사라진다 | 싹이 된 선 ★ **전환점** |
| 금 간 항아리를 쓸어줌 | 쓸어준다 | 금빛으로 변환 |
| 가로등 스위치를 올림 | 올린다 ★ | 빛의 방사 |
| "이번에는 눌렀다" | 전화기를 누른다 ★ | 같은 균열, 빛의 시작 |
| 벤치에 나란히 | **둘** ★ (처음으로 손이 두 개) | 나란한 두 선 |
| "두 번째 봄이 오고 있었다" | 사라진다 | 꽃이 핀 선 ★ |

### "손과 선" 규칙 (원 기획 유지)
1. 한 페이지에 **손 하나, 선 하나.** 예외: 마지막 벤치 장면에서 처음으로 둘
2. **60대의 손.** 거칠고 굵고 주름져 있다. 손 자체가 살아온 시간
3. 선은 처음에 날카롭고 차갑다 → 중반에 금빛 → 후반에 따뜻해진다
4. 마지막 페이지에서 **손이 사라진다.** 선만 남고, 선 위에 꽃

## 4. 제출물 체크리스트

- [ ] 본문 PDF 1개 — 134페이지, 8.625×8.75in(블리드 포함) 또는 8.5×8.5in(블리드 없음), 300DPI
- [ ] 표지 PDF 1개 — 17.552×8.75in, 300DPI, 뒤+책등+앞 한 장
- [ ] 페이지 수가 **짝수**인지 확인
- [ ] 책등 쪽 0.375인치 안에 중요 요소가 없는지 확인
- [ ] 잉크 종류 결정: **표준 컬러 목표** (프리미엄 컬러 회피)

## 5. 확인이 필요한 항목

- **인쇄비 수치**는 KDP 2026 공표 요율($1.00 + 페이지×$0.0255 표준컬러 / ×$0.065 프리미엄컬러) 기준 계산값입니다. 다만 **8.5인치 폭은 대형 판형 요율표가 적용될 수 있어** 실제 비용이 더 높을 수 있습니다. KDP 등록 화면의 인쇄비 자동계산으로 최종 확인 필요.
- 흑백 인쇄비는 "200페이지 흑백 = $3.40" 예시에서 역산한 추정치입니다.
