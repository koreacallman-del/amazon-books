## KDP 규정 확인 기록 (2026-09-27, 검색 스니펫 기반 — amazon.com 직접 접속 차단 환경)
- 카테고리: **형식당 3개** (전자책 3 + 페이퍼백 3). "이메일로 10개 요청" 제도 폐지
- 페이퍼백 최소 페이지: 24 (프리미엄컬러/흑백), 72 (표준컬러), **책등 텍스트는 79+**
- 인쇄는 **짝수 페이지 필수** → 133 → 134
- 안쪽 여백(gutter): 24~150p = **0.375 in** / 151~300p = 0.5 in
- 바깥·위·아래 여백: 0.25 in (블리드 페이지는 0.375 in)
- 블리드: 위·아래·바깥쪽에 각 0.125 in 추가 (책등 쪽 제외)
- 책등 폭 = 페이지수 × 0.002252 (백색지) / × 0.0025 (크림지)
- 인쇄비(US): 표준컬러 $1.00 + 페이지×$0.0255 / 프리미엄컬러 $1.00 + 페이지×$0.065
  ※ 8.5in 폭은 대형 판형 요율이 적용될 수 있음 — KDP 등록 화면에서 최종 확인 필요
- 인세: 페이퍼백 정가의 60% − 인쇄비
- AI 공시: AI-generated(번역 포함)는 신고 의무. AI-assisted는 불필요. 비공개 체크박스라 상품 페이지 미표시. 미신고 시 도서 차단·계정 정지 가능
