# Amazon KDP 규정 요약 (등록 전 KDP 도움말에서 최신 확인)

## 제목·부제
- 제목은 표지와 정확히 일치. 부제에 검색 키워드를 자연스럽게. 키워드 나열형은 반려.
- 넣을 수 없는 것: 다른 저자·책 이름, "bestseller", "free", 순위 주장, 광고 문구.

## 도서 설명
- 4,000자 이내. 허용 HTML: <b> <i> <u> <br> <p> <ul> <ol> <li> <h4>~<h6>.
- 첫 2~3줄이 접힘 전에 보임 → 핵심 약속. 구조: 후킹 → 얻는 것 → 누구를 위한 책 → 저자 신뢰 근거 → CTA.
- 실제 있는 리뷰만 인용. 없으면 넣지 않음.

## 키워드 7개
- 각 50자 이내, 2~4단어 구문형. 제목·카테고리와 중복 낭비. 금지: 타 저자·책명, 상표, "free", 품질 주장. 근거는 researcher의 경쟁 도서 조사.

## 카테고리
- 등록 시 최대 3개. 경쟁 적은 하위 카테고리가 유리하나 내용과 무관하면 삭제 사유.

## AI 콘텐츠 공시 (2026 기준)
- AI가 **생성**한 텍스트·이미지·번역은 공시 필수. 사람이 대폭 편집해도 AI가 원문을 만들었으면 "생성".
- AI가 **보조**(브레인스토밍, 교정, 사람이 쓴 글 다듬기)면 공시 불요.
- 공시는 내부용, 상품 페이지 비표시, 로열티·순위 무관(아마존 공식). 미공시 적발 시 삭제·계정 정지. 숨길 이유 없음.
- 이 시스템에서 writer 초안이 본문이 되면 "AI 생성 텍스트". 표지를 AI로 만들면 "AI 생성 이미지".

## 표지
- 전자책 권장 1600×2560px(1:1.6), 세로 최소 1000px, JPG/TIFF, RGB, 50MB 이하. 썸네일(100px 폭)에서 제목이 읽히는지.
- 종이책 표지는 KDP 표지 계산기로 스파인 폭 산출(페이지 수·용지). 종이책 내지는 별도 조판(Word/Affinity/Vellum) — 이 시스템은 텍스트까지.

## 로열티·기타 (참고)
- 전자책 70% 옵션은 가격 $2.99~$9.99 구간, 배송비 차감. 35%는 제한 없음.
- 미국 원천징수 30%, 조세조약 국가는 세금 인터뷰로 감면. 수치는 등록 시점 재확인.
