# 집필 규칙

## 공통
- 책 언어는 brief.md. 영어면 미국식 영어, 한국어면 합니다체(brief에 예외 있으면 그대로).
- 장 = 하나의 문제 또는 하나의 사건. 첫 문단에 그 장의 핵심.
- 논픽션: 소제목은 질문형 또는 동사형. 절차는 번호 목록, 비교는 표, 장 끝 요약 또는 체크리스트.
- 픽션: 시점·시제 일관(brief에 명시). 장면 단위. 대화문 구두점 규칙 일관.
- 수치·인용·사실은 facts.md에 있는 것만. 없으면 `[확인 필요: 내용]`.
- 같은 설명 반복 금지. 이전 장에서 다룬 것은 한 줄 참조.
- 분량은 outline 지정. 기본 논픽션 장 2,500~4,000단어(영어) / 5,000~8,000자(한국어).

## 파일
- `chapters/chNN.md`, 머리에 `<!-- status: draft | reviewed | final -->`, 제목은 `# N. 제목`.
- 새 용어·고유명사 표기는 `style-sheet.md`에 누적 (editor).

## 금지
- forbidden.md. 다른 책 문장 재사용. 실존 인물에 대한 검증 불가 서술.
